Database Architecture & Schema Setup

The project initiates with a clean, normalized relational database structure consisting of customers, products, and sales tables linked via foreign key constraints, populated with South African business transaction data spanning January to May 2026.

-- Create database
DROP DATABASE IF EXISTS sales_profitability;
CREATE DATABASE sales_profitability;
USE sales_profitability;

-- Customers Table
CREATE TABLE customers (
    customer_id INT PRIMARY KEY,
    customer_name VARCHAR(100),
    customer_type VARCHAR(50),
    city VARCHAR(100),
    province VARCHAR(100)
);

-- Products Table
CREATE TABLE products (
    product_id INT PRIMARY KEY,
    product_name VARCHAR(100),
    category VARCHAR(100),
    unit_price DECIMAL(10,2),
    unit_cost DECIMAL(10,2)
);

-- Sales Table
CREATE TABLE sales (
    sale_id INT PRIMARY KEY,
    sale_date DATE,
    customer_id INT,
    product_id INT,
    quantity INT,
    discount DECIMAL(10,2),
    FOREIGN KEY (customer_id) REFERENCES customers(customer_id),
    FOREIGN KEY (product_id) REFERENCES products(product_id)
);

Analytical SQL Query Suite

To extract granular business insights, a robust suite of analytical queries was written covering overall KPIs, monthly trends, product profitability, and regional performance.

Overall Business KPIs Query

SELECT
    SUM((s.quantity * p.unit_price) - s.discount) AS total_revenue,
    SUM(s.quantity * p.unit_cost) AS total_cost,
    SUM((s.quantity * p.unit_price) - s.discount) - SUM(s.quantity * p.unit_cost) AS gross_profit,
    ROUND(
        (
            SUM((s.quantity * p.unit_price) - s.discount) - SUM(s.quantity * p.unit_cost)
        ) / SUM((s.quantity * p.unit_price) - s.discount) * 100, 2
    ) AS profit_margin
FROM sales s
JOIN products p ON s.product_id = p.product_id;

Monthly Performance Trend Query

SELECT
    DATE_FORMAT(s.sale_date, '%Y-%m') AS month,
    SUM((s.quantity * p.unit_price) - s.discount) AS revenue,
    SUM(s.quantity * p.unit_cost) AS cost,
    SUM((s.quantity * p.unit_price) - s.discount) - SUM(s.quantity * p.unit_cost) AS gross_profit
FROM sales s
JOIN products p ON s.product_id = p.product_id
GROUP BY DATE_FORMAT(s.sale_date, '%Y-%m')
ORDER BY month;

Product Profitability Ranking Query

SELECT
    p.product_name,
    p.category,
    SUM((s.quantity * p.unit_price) - s.discount) AS revenue,
    SUM(s.quantity * p.unit_cost) AS cost,
    SUM((s.quantity * p.unit_price) - s.discount) - SUM(s.quantity * p.unit_cost) AS gross_profit
FROM sales s
JOIN products p ON s.product_id = p.product_id
GROUP BY p.product_id, p.product_name, p.category
ORDER BY gross_profit DESC;

Unsold Inventory Detection (Left Join Analysis)

SELECT
    p.product_id,
    p.product_name,
    p.category
FROM products p
LEFT JOIN sales s ON p.product_id = s.product_id
WHERE s.product_id IS NULL;
